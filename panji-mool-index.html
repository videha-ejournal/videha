तिरहुता आउटपुट
तिरहुता लिपि (Unicode U+11480–U+114DF): देवनागरी स्वर, व्यञ्जन, मात्रा एवं अंक पूर्णतः मैप। चन्द्रबिन्दु (ँ → 𑒿 U+114BF), अनुस्वार (ं → 𑓀 U+114C0), विसर्ग (ः → 𑓁 U+114C1), हलन्त (् → 𑓂 U+114C2) सहित — संयुक्ताक्षर (क्ष, त्र, ज्ञ आदि) स्वचालित रूप सँ परिवर्तित होइत अछि। पूर्णविराम (।) आ दीर्घ विराम (॥) तिरहुतामे सेहो देवनागरी सन प्रयुक्त होइत अछि, से अपरिवर्तित रहैत अछि।

ब्रेल आउटपुट (⠃⠗⠑⠇)
✅ पूर्ण दुनू दिस ब्रेल रूपांतरण (Braille मानक, मैथिली-देवनागरी)
• देवनागरी → ब्रेल: स्वर, व्यञ्जन, मात्रा, संयुक्ताक्षर (विराम), अंक, विराम चिन्ह सब ब्रेल मे बदलैत अछि।
• ब्रेल → देवनागरी: ब्रेल केँ पुनः देवनागरी मे परिवर्तित करैत अछि।
• विशेष: 'ख', 'घ', 'छ', 'झ', 'ठ', 'ढ', 'थ', 'ध', 'फ', 'भ' जकाँ महाप्राण व्यञ्जन केँ दुइ ब्रेल सेल (उपसर्ग ⠘ + मूल व्यंजन) केर रूप मे मैप कएल गेल अछि।
• स्पर्श पठन हेतु: अंक ⠼ + अंक सेल, विराम (।) ⠐⠂, दीर्घ विराम (॥) ⠐⠆।
